How to play

Each chapter contains clues about real places. Find the place named by each clue and write it in the answer field.

Read the first letters of your answers in number order. Those letters make a secret word: the URL path for the next chapter.

  1. Identify the places using your brain, maps, search, or AI.
  2. Type the place names and check your answers.
  3. Copy the resulting letters into the secret-path field.
  4. Unlock the next website-style chapter.

Stuck? Each riddle offers two hints and an optional answer reveal. There's no forced timer and no penalty for mistakes. Progress saves on this device.

This is a playful puzzle game, not an actual secure vault. The source code is visible to anyone using browser developer tools.
